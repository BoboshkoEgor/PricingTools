Global pricing metrics — narrated lecture

About 15 minutes: 21 slides with a narrator and captions, and a checkpoint after each module. Interactive mode waits for your answers; Video mode reads questions aloud, pauses, and reveals answers — use it for recording.

Keys: Space — play/pause · ← → — previous/next · F — full screen. The narrator uses your browser’s built-in voices; Microsoft Edge has the most natural ones (“… Online (Natural)”).

Turn this into an MP4 video (free tools, no registration)

Option 1 — OBS Studio (Windows, macOS, Linux)

  1. Install OBS Studio from obsproject.com — free, no account.
  2. Open this file in Microsoft Edge (best voices) or Chrome. Set Mode: Video, pick a voice, check captions on or off.
  3. In OBS, add a source: Window Capture (choose the browser window) or Display Capture. On macOS 13+ use macOS Screen Capture, which also records the browser’s sound.
  4. Check that Desktop Audio moves in the OBS mixer when the narrator speaks.
  5. Settings → Output → Recording format MP4; Settings → Video → 1920×1080, 30 fps.
  6. Press Full screen here, then Start Recording in OBS, then Space to play. Stop recording after “End of the lecture”.

Option 2 — built into the system

  • Windows 10/11: focus the browser and press Win + Alt + R (Xbox Game Bar). It records the window with system sound to Videos → Captures.
  • macOS: Cmd + Shift + 5 records the screen but not system sound without an extra audio driver — use OBS instead.

Option 3 — trim or compress (optional)

  • LosslessCut or Shotcut (free, no account) to trim the start and end.
  • Or ffmpeg: ffmpeg -i recording.mkv -c:v libx264 -crf 23 -c:a aac lecture.mp4
